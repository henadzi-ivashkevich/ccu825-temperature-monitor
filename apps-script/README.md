# Google Apps Script

`Code.gs` — единый скрипт для приёма измерений через `doPost(e)` и выдачи истории через `doGet(e)`. Он использует таблицу `мониторинг`, записывает 16 входов по текущей формуле, а также семь выходов, заряд и состояние батареи, `Power` и температуру платы `Temp`.

## Установка

1. В Apps Script вставьте содержимое `Code.gs` вместо текущего кода. Значение API-токена в исходник не вставляйте.
2. В настройках проекта создайте Script Property с именем `API_TOKEN` и новым секретным значением.
3. Установите такое же значение в POST-запросе Automate (в поле `token`).
4. Сохраните и разверните новую версию веб-приложения.

Скрипт при первой записи сам добавит в конец существующего листа недостающие заголовки для выходов, батареи, `Power` и температуры платы. При последующих запросах новые колонки повторно не добавляются.

Не сохраняйте API-токен или экспорт Automate с токеном в Git. Токен из ранее присланного кода следует заменить новым до обновления потока и Script Property.

## API

- `POST /exec`: тело `{ "token": "…", "payload": { …ответ CCU… } }`; токен сверяется с Script Property `API_TOKEN`.
- `GET /exec?action=history&from=YYYY-MM-DD&to=YYYY-MM-DD`: возвращает историю для Android-приложения. `doGet` в текущей версии не проверяет токен; настройте доступ веб-приложения соответствующим образом.
