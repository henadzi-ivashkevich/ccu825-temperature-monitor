# Google Apps Script setup

Эти файлы добавляются в Apps Script-проект, который уже выполняет первый запрос к CCU825 и записывает входы в Google Sheets. Они не являются заменой существующего `doPost(e)` и конфигурации проекта.

## Дополнительные поля из ответа CCU

`ccu-extra-columns.gs` добавляет в конец таблицы 11 столбцов: семь выходов, заряд батареи, состояние батареи, `Power` и температуру платы (`Temp`). В существующем коде записи замените:

```javascript
sheet.appendRow(baseRowValues);
```

на:

```javascript
appendCcuMeasurementRow_(sheet, baseRowValues, ccuResponse);
```

`baseRowValues` — существующий массив с временем и 16 входами. `ccuResponse` может быть распарсенным объектом или объектом `HTTPResponse` от `UrlFetchApp`. Помощник сам добавит недостающие заголовки и запишет все значения на ту же строку. Не вызывайте вслед за ним старый `appendRow`, иначе появится дублирующая строка.

Новые заголовки:

```text
Выход 1, Выход 2, Выход 3, Выход 4, Выход 5, Выход 6, Выход 7,
Заряд батареи, %, Состояние батареи, Power, Температура платы, °C
```

Поля берутся непосредственно из `ccuResponse.Outputs`, `ccuResponse.Battery.Charge`, `ccuResponse.Battery.State`, `ccuResponse.Power` и `ccuResponse.Temp`. Значение `Temp` записывается как температура платы; формула преобразования не применяется.

## История для Android-приложения

`temperature-history.gs` добавляет GET-обработчик `action=history`. В проекте должен быть только один `doGet(e)`: если он уже существует, объедините в нём ветку `action=history` с прежними действиями. Обработчик использует существующие константы `SPREADSHEET_ID` и `SHEET_NAME` и точные заголовки 16 входов из корневого README.

После внесения изменений сохраните и разверните новую версию Apps Script как веб-приложение. Уровень доступа настройте в соответствии с вашей моделью доступа к таблице; URL развёртывания не коммитьте.
